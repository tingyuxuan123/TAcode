## 产品行为

### 文件
顶部统一标签、面包屑与工具栏，中间代码，右侧可调宽/折叠文件树。目录多级展开，文件类型图标、Git 状态、路径搜索、当前文件定位；隐藏和生成目录可按需展开。
预览/固定标签、拖动排序、关闭其他标签；工具记录、聊天路径和审查中的文件入口统一。
支持创建文件/目录、重命名、移入废纸篓、复制路径、系统文件管理器和外部编辑器打开。
CodeMirror 6 提供行号、高亮、查找替换、行定位、撤销重做、换行及保存。外部修改无编辑时刷新，有编辑时比较并处理冲突；关闭、换项目、退出和重启保护未保存内容。
Markdown/HTML 源码与渲染切换；图片/SVG 预览；二进制展示类型大小和外部打开。
首版 UTF-8/UTF-8 BOM 文本完整编辑上限 4 MiB，保留 CRLF/LF/BOM 和权限；超限分块只读，截断文本不允许写回。

### 审查
未暂存为默认；提供未暂存（含未跟踪）、已暂存、指定提交、相对分支、最近一轮。
顶部范围/统计/操作，中间连续多文件 diff，右侧变更树；统一/左右对照、单词级差异、上下文展开、折叠、筛选、跳转和滚动联动。
整批、单文件、单 hunk 暂存/取消暂存/还原；提交、推送、提交并推送。
评论支持单行/多行，选中意见及代码位置进入当前对话草稿，用户发送后执行修复。
AI 审查读取冻结范围，返回严重程度、位置、证据与覆盖情况；支持取消、失败重试、后台和历史。

## 实现规则

- 编辑器 CodeMirror 6；diff @pierre/diffs，复用 React 19 / Shiki 4，使用本地打包 Worker 与虚拟滚动。语言包按需加载。
- 文档键为项目+规范化路径；标签视图按项目+会话保存。主进程路径检查包含 realpath；渲染层无 Node 权限。
- 文件服务统一索引/目录分页/路径搜索/读取/写入/监听；复用现有 @ 补全索引。读取状态含 text/empty/missing/binary/error/truncated 及独立元数据，不把提示拼进内容。保存带 expectedVersion 并原子替换。
- typed IPC 扩展 workspace 文件服务，新增 git 与 review 服务；事件携带项目标识。异步请求按项目/版本丢弃过期结果。HTML/图片预览 URL 绑定项目，禁止依赖易变的全局 active cwd。
- Git CLI 使用异步子进程与参数数组，禁用 external diff/textconv，路径精确处理。仓库写操作串行；监听工作区、index、gitdir/common-dir refs。缺 Git/非仓库有明确入口，文件功能独立工作。
- 未暂存= index 到工作树，含未跟踪；已暂存= HEAD 到 index。指定提交默认第一父提交到该提交，根提交从空树比较。分支=用户所选基准 merge-base 到 HEAD，首次选择并记忆。
- 历史范围只读；写操作由后端基于当前快照生成并预检补丁，拒绝过期/不匹配操作。未暂存还原以 index 为基准；已暂存还原使用逆向补丁更新 index/工作树并保护额外未暂存修改，重叠失败不自动覆盖。还原建立恢复点；Git 操作与 Agent /undo 分离。
- 提交前展示实际 index 和分支，空 index 提供显式暂存入口。推送优先当前上游；无上游时选择远端/分支。沿用系统 Git 身份与凭据，失败保留状态，不静默重试写操作。
- 最近一轮用请求起止快照，不从工具累计计数推测。截止点为 agent_settled/停止；仍运行命令有标记，后续磁盘变化由实时 Git 显示。旧转录缺快照显示覆盖限制。
- AI ReviewCoordinator 复用 AgentHost/code-reviewer 配置并硬性限制只读能力；结果绑定 snapshotId、path、side、lineRange，校验定位，内容改变显示过期。角色禁用/模型不可用有具体处理入口。
- 计划确认保留于聊天工作流，/undo 保持原语义。所有新控件有中英文、IME 保护、键盘焦点与 aria 标签。
