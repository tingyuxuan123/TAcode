# FR-03：真实 Git 审查工作区验收

2026-09-14，独立工作树 `codex/file-review-workbench`。本阶段把 FR-01 的审查组件接到 FR-02 的真实 Git 读取器。

## 可用行为

- 默认未暂存，包含未跟踪文件；已暂存、指定提交、相对分支四种范围均读取真实 Git 快照。提交可输入引用或 SHA，根提交比较空树；基准分支由用户选择并按项目记忆，展示 merge-base 与 HEAD 的实际 SHA。
- 连续多文件 diff、右侧变更树、完整路径筛选、文件定位、统计、统一/左右布局、单词差异、上下文展开与文件折叠。目录随异步结果展开，首次组件加载期间的文件点击会在就绪后定位；列表末尾的滚动边界不会改掉用户刚选中的文件。
- 空文件、二进制、读取超限、冲突、符号链接、子模块和权限变化有独立呈现。非文本状态没有伪造代码行；完整文本保留以展开省略的上下文。Git 版本和内容可用状态共同参与 diff 缓存身份。
- 缺 Git、非仓库、无可选分支、错误提交引用和读取失败有具体状态与重试入口；在已打开目录执行 `git init` 后可自动进入审查。
- Git 审查替换原审查标签。计划确认、调整计划和“撤回上一轮改动”移到聊天消息列表中，继续调用原有 Agent 工作流；`/undo` 语义不变。

## 跨层约定与资源生命周期

`shared/git.ts` 定义 `GitApi`、查询、结果与事件；生产 preload 提供 `git.subscribe`、`unsubscribe`、`refresh` 和 `onUpdate`。主进程 `git-ipc.ts` 校验绝对项目路径、引用长度和订阅标识，仅接受工作台主 frame；项目必须通过现有已打开项目校验。

`GitReviewService` 按规范化项目路径与比较范围合并读取。订阅在异步授权前登记，因此切项目、关闭或页面重载能取消尚未完成的授权；每个订阅属于发起窗口。读取中发生变化会丢弃过期结果并重新读取，最后一个订阅关闭时终止读取并释放监听。

监听工作区、独立 gitdir/index、common-dir refs，约 180 ms 合批。Git 对象、日志和锁文件的噪声不会触发 metadata 刷新；普通工作文件变化只刷新未暂存范围。原生监听不可用时显示定时刷新状态，1 秒轮询并重试建立监听；轮询不会让耗时读取一直失效。

渲染层 `GitReviewStore` 同时核对项目、查询、订阅 id 和事件序号。切换范围不会显示上一范围的数据；同范围刷新时保留不可变结果并显示忙碌状态。标签隐藏、外层抽屉关闭或页面隐藏后取消订阅并卸载 diff，两个本地高亮 Worker 随之终止；返回时重新读取，恢复滚动位置。

## 第三方库修正

`patches/@pierre__diffs@1.4.2.patch` 固定修正 CodeView 的尺寸调度：将 ResizeObserver 中同步进行的布局更新合并到下一动画帧，reset 时取消待处理帧。真实混合文件列表切换左右布局曾稳定出现 ResizeObserver loop 提示；修正后同一回归无此提示。没有屏蔽浏览器错误或替换全局 ResizeObserver。
