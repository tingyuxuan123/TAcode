**UX-06 启动与历史整理对照**

2026-09-13，Apple M5，macOS / Darwin 25.6.0，Electron 37。同一次构建生成的生产 renderer、preload 与 Electron 测试入口，每组运行三次；使用独立临时数据目录，不读取实际账户，不请求模型。每个合成会话包含一条问题与一条回复。

`blocking` 在创建窗口前等待全量历史分区，再由列表请求索引会话；`deferred` 先准备目录和配置，在窗口出现后逐条整理和索引，整理期间列表从现有 SQLite 索引读取。两组使用相同分区实现，这里测量启动顺序的影响，不是两个历史发行版本的整机比较。

计时从 Electron ready、样本准备完成后开始，到 `ready-to-show`、首个可用项目按钮、输入框可编辑分别结束。输入耗时包含聚焦、插入文字与读取结果。表格为三次中位数，单位 ms。

| 会话数 | 窗口：阻塞 → 后台 | 侧栏可操作：阻塞 → 后台 | 输入框就绪：阻塞 → 后台 | 输入响应：阻塞 → 后台 |
| --- | --- | --- | --- | --- |
| 0 | 172.9 → 168.0 | 243.3 → 230.2 | 271.0 → 274.7 | 2.1 → 2.0 |
| 100 | 210.4 → 175.4 | 346.0 → 257.8 | 354.3 → 265.2 | 3.0 → 2.7 |
| 1000 | 586.6 → 177.5 | 1135.7 → 246.1 | 1181.1 → 265.2 | 15.7 → 2.1 |

1000 会话样本的窗口等待减少约 70%，侧栏等待减少约 78%；历史整理全部完成仍需约 1159 ms。窗口出现后索引继续工作，每约 200 ms 发布一批进度与可用记录。零会话样本的几毫秒差异处于启动噪声内，不解释为优化收益。

测试还确认：整理期间可以输入，最终会话数量正确，未启动 Agent worker。文件系统缓存来自刚生成的样本；这不是冷盘、超长转录、真实账户或全部插件的启动基准。首次迁移中的顶层配置/索引复制仍需在窗口之前完成，以保留设置；会话目录复制和整理在后台执行。
