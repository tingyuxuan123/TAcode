## 背景：先量测，再改（探针跑在 session scratch，没动仓库）

用生产样式表 `src/renderer/styles.css` 在真实 Electron（Chromium 138，仓库 electron ^37）里量测两块界面，得到的事实：

**A. 主会话 markdown 表格（`.turn > .stream > .markdown > table`，760px 宽）**
- `.turn { overflow-wrap: anywhere }`（`styles.css:1774-1781`）+ `.markdown table { width: 100% }`（`styles.css:2253`）让中间长列独占宽度：中间列 522px，末列只剩 **61px**。
- 结果：`置信` 列「已核实」被拆成两行（文本 rects = `[27px, 13px]`），首列 `completed` / `cancelled` 同样被拆行（`[57,8]` / `[51,8]`）。**这就是截图里「已核 / 实」的直接原因。**
- 表格用 UA 默认 `ul/padding`，`.markdown ul` 只设了 margin，没设缩进。

**B. 子代理面板报告区（`child-session-panel.tsx:153` 复用了抽屉的紧凑样式）**
- 容器是 `.delegate-task-output.markdown`（`styles.css:3306`，为 420px 抽屉写的）：正文 **11px / 行高 15.95px**、行内 code **10.5px 且背景透明、padding 0**（`styles.css:3369-3372` 把 code 装饰全部抹掉）、`ul` 缩进 **40px**（等于正文 3.6em）、file chip 只有 **9.35px**（0.85em × 11px）且只显示 basename。
- 同一块 CSS 在面板里字号混用两套缩放变量（容器 `--ui-font-scale`、markdown 子元素 `--chat-font-scale`）。
- `.child-session-report` 在 CSS 里已定义（`styles.css:7405`）但**没有任何地方使用**——本来就是留给面板的容器。

## 改动清单

### 1. 新增 `src/renderer/markdown-table.ts`（纯函数，可单测）
- `isTightTableCell(text)`：去空白后**不含空白字符且长度 ≤ 12** → `true`（覆盖 `completed`、`cancelled`、`:609`、`已核实`）。
- 语义：这类单元格是「不可再压缩的短标签」，必须禁止被压缩到拆行。

### 2. `src/renderer/ui.tsx` 的 `Markdown` 组件（`ui.tsx:1291-1320`）
- `components` 增加：
  - `table` → `<div className="md-table-wrap">…</div>` 包一层（表格过宽时横向滚动，而不是把列挤成 1 字）。
  - `th` / `td` → 用已有的 `extractNodeText()` 判定，短文本加 `class="is-tight"`；显式透传 `align` / `style`（保住 GFM 对齐），**不 spread 未知 props**（避免 `node` 落到 DOM 上）。
- 现有 `code` / `pre` 覆盖逻辑不动（file chip 判定不变）。

### 3. `src/renderer/styles.css`
- 新增：`.md-table-wrap { max-width: 100%; overflow-x: auto; }`
- 新增：`.markdown th.is-tight, .markdown td.is-tight { white-space: nowrap; }` → 短标签不再拆行，表格自动把宽度还给它们。
- 新增：`.markdown p, .markdown li { text-wrap: pretty; }` → 收掉正文末尾只剩 1–2 字的孤儿行（截图里段落末尾的「已核 / 实」属这一类）。
- 启用 `.child-session-report.markdown` 一组规则（面板专用，替换掉抽屉那套）：
  - 正文 `calc(12.5px * var(--chat-font-scale))` / `line-height: 1.6`；标题比抽屉大一档；
  - `ul, ol { padding-left: 1.35em }`（40px → ~17px），列表缩进恢复正常；
  - 行内 `code` 恢复 `--md-code-bg` 底 + 小内边距 + `overflow-wrap: anywhere`（面板里 `inspect={<InspectPanel />}` 这类不再是「没格式的等宽字」）；
  - `pre` 保留浅底、取消抽屉的 `padding: 0`；
  - `th, td { padding: 6px 10px }`；`.file-chip { font-size: .92em }`。
- **抽屉 `.delegate-task-output` 一行不改**（420px 场景维持现状，零回归面）。

### 4. `src/renderer/browser/child-session-panel.tsx`
- 第 153 行报告容器 `className="delegate-task-output markdown"` → `"child-session-report markdown"`。
- 面板其余结构（表头 meta、活动流、轮询）不动。

### 5. 可选项 B：`src/renderer/file-path-chip.tsx` + `src/renderer/file-path.ts`
- 现状 chip 只显示 basename（`panel-state.ts:12-15`、`App.tsx:1758`），在多文件审计报告里无法区分同名文件。
- 改为「保留末两段路径 + 行号」（`browser/panel-state.ts:12-15`），`title` 给完整路径；新增纯函数 `chipLabel(path)` + 单测。
- 影响面是聊天全局的 chip 文案，故列为可选项，按你的答复决定做不做。
