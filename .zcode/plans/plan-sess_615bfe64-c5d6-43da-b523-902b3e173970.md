# TACode 侧边聊天复刻 Codex 模式

## 目标语义（对照 Codex）
1. **锚定来源**：侧边聊天从主聊天发起（选中文字 / `/side` / 快捷键），记录 sourceSession，预填选中文字为草稿
2. **声明式临时**：空态明示「临时聊天，关闭应用后消失」；关闭 tab 弹破坏性确认（带「不再询问」，localStorage）；主进程启动时清理 `~/.tacode/side-chats`（实现"关闭应用后消失"，落盘仅作 crash 兜底）
3. **多实例编号**：「侧边聊天 1/2/3」，+ 菜单和 `/side` 每次新建，ordinal 补空位（照抄 Codex 的 ordinal 分配）
4. **生命周期健壮**：停止/失败后不再出现死 runtime 裸错误——消息保留、显示「已结束」+「开始新的侧边聊天」重建按钮；发送失败回滚输入文本
5. **禁止嵌套**：侧边聊天 composer 无斜杠命令、选中工具条只挂主聊天转录区，天然满足

## 明确取舍（写进代码注释/文案）
- 保持惰性 start：开 tab 不建 runtime，首条消息才创建并快照 cwd/model/permission（省资源，临时语义兼容）
- 上下文注入 = 选中文字预填草稿（用户确认后发送），不做主会话转录 fork
- 快捷键聚焦最新、+/side 新建，避免快捷键连按爆 tab
